⚡ QUICK START (Local Development)

1. Clone repository:
   git clone https://github.com/halee-z/Todo.app_phase.2.git

2. Backend setup:
   cd backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python -m uvicorn src.main:app --reload

3. Frontend setup (new terminal):
   cd frontend
   npm install
   npm run dev

4. Open browser:
   http://localhost:3000

🚀 PRODUCTION DEPLOYMENT (20 minutes)

STEP 1: Prepare Neon Database (5 min)
   • Create database at neon.tech
   • Save connection string

STEP 2: Generate JWT Secret (1 min)
   • Create random 32+ character secret

STEP 3: Deploy Backend (5 min)
   • Run: cd backend && vercel --prod
   • Set environment variables in Vercel UI
   • Save backend URL

STEP 4: Deploy Frontend (5 min)
   • Update .env.production with backend URL
   • Run: cd frontend && vercel --prod
   • Save frontend URL

STEP 5: Configure CORS (2 min)
   • Update backend ALLOWED_ORIGINS with frontend URL
   • Redeploy backend

STEP 6: Test Deployment (5 min)
   • Sign up for account
   • Create and manage tasks
   • Verify all workflows

TOTAL TIME: ~23 minutes
